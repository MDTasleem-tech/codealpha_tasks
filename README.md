# CodeAlpha Task 1 — Student Grade Tracker

A Java console application for managing student marks and generating academic performance reports.

## Features
- Add multiple students
- Enter marks for five subjects
- Validate marks between 0 and 100
- Calculate total and average marks
- Find highest and lowest marks
- Assign grades
- View individual student reports
- Generate a class summary and identify the topper

## Technologies
- Java
- Arrays and ArrayList
- Object-Oriented Programming

## How to Run

Make sure Java JDK is installed.

Compile:

```bash
javac StudentGradeTracker.java
```

Run:

```bash
java StudentGradeTracker
```

## Data Storage
Student records remain in memory while the program is running. They are not saved permanently after exiting.
