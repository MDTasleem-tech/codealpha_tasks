# Stock Trading Platform

## About the Project
Stock Trading Platform is a Java console application that simulates stock trading using virtual money. Users can view sample stock prices, buy stocks, sell owned stocks, and view their portfolio.

## Features
- View simulated stock market prices
- Start with ₹100,000 in virtual cash
- Buy stocks with quantity validation
- Sell stocks only when sufficient shares are owned
- View stock holdings and portfolio value
- View available cash and total account value
- Menu-driven console interface

## Technologies Used
- Java
- Object-Oriented Programming concepts
- Arrays
- Loops and switch statements
- Scanner for user input

## Stocks Included
- TCS
- Infosys
- Wipro
- Reliance

**Note:** Stock prices are simulated for educational purposes. This application does not use live market data or real money. Account data resets when the program exits.

## How to Run

1. Install the Java Development Kit (JDK).
2. Open a terminal in this project folder.
3. Compile the program:

   `javac StockTradingPlatform.java`

4. Run the program:

   `java StockTradingPlatform`
